# 자판기 음료 공통코드 준비 (V14)

이 변경은 기존 기능을 유지하면서 COIN_REASON에 COLA·CIDER·FANTA·WATER 네 항목만 추가한다. coin_events가 공통코드를 외래 키로 참조하므로 기능보다 먼저 준비한다.

1. 준비 PR을 main에 병합하고 기존 절차로 13..14 호환 릴리스를 배포한다.
2. 운영 담당자가 기존 `deploy/migrate-prod.py`로 백업·V14 적용·검증을 수행한다. 실행 중 릴리스도 V14를 허용해야 한다.
3. 그 다음 자판기 기능 PR(14..14)을 병합하고 배포한다. V13에서 기능 릴리스를 배포하는 것은 기존 호환성 검사로 거절된다.

배포·시작·롤백에 자동 마이그레이션을 추가하지 않는다. 이 작업에서 운영 DB 접속이나 마이그레이션 실행은 하지 않았다. 실제 PostgreSQL 마이그레이션 검증은 CI의 폐기 가능한 DB에서 수행한다.
