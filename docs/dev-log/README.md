## 로그 작성 규칙 (Claude)
- 파일 이름은 `YYYY-MM-DD.md`로 하고, 같은 날 작업은 같은 파일에 이어 쓴다. 맨 앞에 작성일을 적는다.
- 항목마다 다음 순서로 쓴다: PR 번호 → 구현 → 주요 소스 표(경로 | 내용) → 기술 포인트 → 트러블슈팅(증상 → 원인 → 해결) → 관련 문서.
- 측정 수치는 실제로 잰 값만 적고, 확인하지 못한 것은 그렇다고 적는다.
- 서버 IP·도메인·계정 같은 운영 정보는 적지 않는다.
